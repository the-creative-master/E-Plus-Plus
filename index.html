    Libraries (1.3.5)

    Both word orders work:
    add library "Math" or add the "Math" library

    Python add library "Python"

    Runs single-line or multi-line Python code, loops, functions, and math inside E++.

    Math add library "Math"

    Unlocks square roots, percentages, min/max, absolute value, pi, power, and trig.

    Random add library "Random"

    Generates random numbers between bounds, 20-sided dice rolls, and coin flips.

    Strings add library "Strings"

    String length, uppercase, lowercase, reverse, first/last letter, and trimming.

    Time add library "Time"

    Current time, date, calendar year, unix timestamps, and wait/sleep delays.

    Files add library "Files"

    Read from file into variables, write new files, and append data to files.

    Colors add library "Colors"

    Colored terminal messages: red, green, blue, yellow, cyan, and magenta.

    System add library "System"

    Platform architecture, operating system name, and command execution.

    Console add library "Console"

    Clear screen and real-time terminal stream management.

    This is the E++.zip build: Colors, Draw, Game and ImprovedWait live in the full Studio. Keyboard and ImprovedWaitLite are here.

    ImprovedWaitLite is only in E++.zip; this Studio has the full ImprovedWait, with every wait feature.

    Draw Studio only

    Turn any variable into a drawing cursor. Animate its trail at a chosen speed, or move instantly.

    Game add library "Game"

    The pygame zero of E++: a game window, actors with pictures, movement, collisions and a game loop. Link a picture to a name with the 🖼 Image button, then create the actor 'hero'. Not inside E++.zip.

    Keyboard add library "Keyboard"

    if the "Up arrow" key is pressed then ... — arrows, space, enter and every letter. Inside E++.zip.

    ImprovedWaitLite add library "ImprovedWaitLite"

    Named waits, wait until, wait at most and wait ... and then .... Inside E++.zip.

    ImprovedWait add library "ImprovedWait"

    Everything in ImprovedWaitLite plus actors: wait for an actor to finish, stop or pause another actor. Not inside E++.zip.
